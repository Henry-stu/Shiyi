# 使用指南

[返回项目首页](../README.md)


1. 新建文章，填写标题并输入或粘贴正文；标题为空或只有空格时，保存会提示「文章标题还未命名」，点「去命名」后补齐标题才能保存。标题与正文摘要独立显示。
2. 在「标记」模式用手指直接划过文字。单击普通文字可标记单字，双击红字取消整处挖空；重叠和紧邻范围合并。
3. 长文可切到「浏览」模式滚动；「标记」模式下从文字以外的卡片内边距或行间空白拖动也会临时进入浏览并在抬手后恢复标记，文字起点仍用于划选。连续划选到屏幕边缘可自动滚动。用撤销、重做调整，点右上角「完成」保存。
4. 背诵时点击空白显示单处答案，约 5 秒后隐藏；再次点击可立即遮住。右侧工具栏的「全部显示」会取消单处计时并持续展示整篇答案。
5. 点击「编辑正文」修改错字。未受影响的挖空跟随移动，受影响的挖空在保存前显示取消数量；可以返回继续检查。
6. 启动进入独立资料库，点击卡片进入背诵页。宽度达到 720dp 时资料库显示两列，窄屏显示一列；文章页不显示目录。返回后保留搜索、分类和列表位置。
7. 背诵页右侧点击工具入口展开图标栏，可编辑挖空、编辑正文、全部显隐和调整字号；再次点击入口收起，正文不重新换行。长按图标可查看名称。
8. 首页右上角三个点左侧的「＋」可导入 Markdown 文件、PDF 文件和 PNG图片，各类型配有图标。选中文件后在本机提取文字，先预览、修改独立标题及正文；图片识别结果需要对照原文件核对，勾选后点「导入文章」才会保存并进入挖空编辑。取消选择、放弃预览或读取失败不会创建文章。首页「更多」提供设置、草稿、导出与恢复 ZIP 备份；文章菜单提供标题与资料操作、显示设置。恢复会创建新集合，不覆盖现有资料；导入的文件夹保留原名称。
9. 首页长按文章卡片不松手，拖到分类栏的文件夹上，看到「松手移入」后松手即可归类。其他卡片轻微抖动，目标文件夹高亮；拖到分类栏左右边缘会自动滚动。拖到「未分类」可移出文件夹；拖到「全部」、原文件夹或空白处不移动。普通滑动仍是滚动，菜单中的移动入口保留。

正文和挖空编辑的草稿与正式文章分开保存；退出编辑时可以保存、放弃或继续编辑。下次启动可以恢复未完成草稿。临时答案显示状态不会保存，离开页面或切到后台会重置。

导入支持 UTF-8、带 BOM 的 UTF-16 Markdown；如文件无法严格解码，明确确认编码后可以按 GB18030 重试。保留 Markdown 源文本，不把图片、链接或表格转换成富文本。PDF 逐页提取原生文字，扫描页或大图覆盖的页面使用离线 OCR，按原页序合并。未能完整读取的文件不会输出缺页正文。

PNG/扫描件可能有错字、漏字和阅读顺序差异，必须校对。PNG 直接显示适应宽度的原图与可编辑正文，平板宽屏左右对照、窄屏上下排列；点图可全屏放大、双指缩放及拖动。PDF 与 Markdown 直接显示可编辑正文，不显示逐页图片。三个类型均无「校对文字／逐页对照」切换按钮，保留系统「打开原文件」。标题默认建议使用文件名，与正文分开编辑，不从正文开头生成。

当前限制：Markdown 8 MB，PDF/PNG 32 MB；PDF 30 页；PNG 2400 万像素，超 800 万像素会缩采样；正文 100 万字符。识别过程中可取消，在当前识别单元结束后响应；旋转和短暂切后台保留任务及预览。进程被系统结束后，未确认的导入需重新选择文件。导入入口仅在主页出现，若主页选中了文件夹，新文章归入该目录。

1.3.4 OCR 安装包针对当前手机和平板的 arm64 设备；最低 Android 8.0。两份离线模型随包提供，首次识别复制到本机私有目录并校验，后续无需下载。依赖及模型来源、许可证见 [第三方声明](../THIRD_PARTY.md) 和 APK 内 `assets/licenses/`。

**资料仅保存在本机。卸载应用会删除资料，卸载前请手动导出备份。覆盖安装同签名 APK 会保留资料。** ZIP 包含正文，请妥善保存。备份不包含草稿、主题和字号；请先保存编辑再导出。
